YOUR WEBSITE FILES

This folder contains:
- index.html — the page and your text
- style.css — the Warm Paper appearance

To publish with GitHub Pages:
1. Create a new PUBLIC repository with an unidentifiable name.
2. Upload index.html and style.css to the top level of the repository.
3. Open Settings, then Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait for the Pages link to appear in Settings > Pages.

Important: GitHub Pages websites are public on the internet. The noindex tags ask search engines not to list the page, but they do not make it private or prevent access by anyone who has the URL.
